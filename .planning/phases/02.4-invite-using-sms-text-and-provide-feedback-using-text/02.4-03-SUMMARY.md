## Decisions Made
- `sendFeedbackEmail()` uses double `.eq()` guard (`id` + `coach_id`) on video query — effectively replicates RLS at query level without requiring an explicit Supabase policy on `video_analyses`
- Athlete email fetched from `coach_athletes` by `athlete_id` — only accepted (active) athletes have `athlete_id` populated; pending-invite athletes excluded by design (acceptable edge case per plan)
- `handleSendFeedbackEmail` always passed to `MechanicsSidebar` (never undefined) — "no athlete assigned" error surfaces after the click rather than disabling the button, since the review page server component already authenticates coach access
