## Decisions Made

- `lg:min-h-0` on flex children: CSS flexbox `min-height` defaults to `auto` which allows a flex item to grow infinitely even when the parent has a bounded height. Adding `min-h-0` resets this to zero so the flex item respects the parent's height boundary and the inner `overflow-y-auto` div can activate scroll correctly. No effect on mobile where layout is `flex-col` stacked (no height boundary on the parent).
