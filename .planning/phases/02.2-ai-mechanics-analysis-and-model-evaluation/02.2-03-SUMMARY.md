# Phase 2.2 Plan 03: Motion-Dispatched Mechanics Flags Summary

**One-liner:** Motion-type dispatch in `flagMechanics()` with `detectBatCasting` for hitting and `detectPrematureShoulderOpening` for pitching.

## What Was Built

`src/lib/pose/flags.ts` was refactored from a single flat function into a motion-dispatched architecture:

- `flagMechanics()` now accepts a 5th `motionType: MotionType = 'hitting'` parameter and dispatches to `flagHittingMechanics()` or `flagPitchingMechanics()` based on it.
- `detectBatCasting()` — new batting-specific flag. Fires when the lead wrist (left wrist for RHH) is more than 0.6x shoulder-width away from the lead hip. Indicates a long, looping swing path.
- `detectPrematureShoulderOpening()` — new pitching-specific flag. Fires when shoulder tilt is near 0 (open) while hip rotation is below 30 degrees (hips not yet driven). Indicates broken kinetic chain sequencing.
- `flagHittingMechanics()` — internal function containing all original hitting flags (Elbow Drop, Elbow Too High, Excessive Shoulder Tilt, Early Hip Rotation) plus the new Bat Casting detection.
- `flagPitchingMechanics()` — internal function with Elbow Drop (shared) plus Premature Shoulder Opening.

All existing exports (`markContactFrame`, `checkFramingQuality`, `IDEAL_RANGES`, `FLAG_CONFIDENCE_THRESHOLD`) are unchanged. Existing 4-argument callers compile without modification.

## Decisions Made

1. **flagMechanics default parameter** — `motionType: MotionType = 'hitting'` ensures zero-diff backward compat; all existing callers pass 4 args and remain unaffected.
2. **'unknown' routes to hitting** — Preserves behavior for all videos uploaded before Phase 2.2 when motion_type column defaulted to 'unknown'.
3. **RHH hardcoding in detectBatCasting** — Left-handed hitter support deferred; documented as limitation in JSDoc comment.
4. **shoulderWidth guard in detectBatCasting** — Side-view frames where shoulder X-separation is < 0.05 (normalized) are skipped; shoulder width cannot be measured reliably from that angle.
5. **Fixed 0.75 confidence in detectPrematureShoulderOpening** — The function receives computed angle scalars (not raw landmarks), so per-landmark visibility is unavailable. Fixed proxy confidence documented.
