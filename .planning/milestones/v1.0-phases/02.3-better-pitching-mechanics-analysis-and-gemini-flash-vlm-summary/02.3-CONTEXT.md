# Phase 02.3: Better Pitching Mechanics Analysis and Gemini Flash VLM Summary - Context

**Gathered:** 2026-03-01
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 02.3 delivers two things:

1. **Two new pitching-specific mechanics flags** added to `flagPitchingMechanics()` — Arm Circle (Bent Elbow) and Stride Off Power Line. These are the most impactful gaps in the current windmill detection set.
2. **Gemini Flash VLM commentary** wired into the review page Session Summary section — on-demand button, contact-frame analysis, coach-to-athlete voice, saved to DB.

Pitching angle labels also get renamed in the sidebar (e.g., "Hip Drive", "Arm Slot") and ideal ranges are updated with pitching-specific biomechanics data.

This phase does NOT add left-handed pitcher support, session-level replay annotations, or scoring.

</domain>

<decisions>
## Implementation Decisions

### New Pitching Flags
- Add exactly **2 new flags** to `flagPitchingMechanics()` in `flags.ts`:
  1. **Arm Circle (Bent Elbow)** — detects when the pitching arm elbow angle drops significantly below the ideal extended-arm threshold during the wind-up portion of the delivery. Claude has discretion on: (a) the exact elbow angle threshold, (b) how to identify "wind-up frames" without explicit phase segmentation (e.g., frames before the contact frame where elbow should be extended).
  2. **Stride Off Power Line** — detects when the stride foot lands significantly off the pitcher's hip line. Both open strides (foot too far toward 1st base) and closed strides (foot too far toward 3rd base) are flagged. Claude has discretion on: (a) which landmarks define "stride foot" and "hip line" for a right-handed pitcher, (b) the offset threshold that constitutes "significant".
- Both flags use the **same amber/red FlagPanel style** as existing hitting flags — no separate grouping or sub-section

### Gemini VLM in Session Summary
- A **"Get AI Commentary" button** sits in the Session Summary section (rendered by `AnalysisSummary.tsx`) — below the "Needs Work" / "Looking Good" lists
- Clicking the button sends the **contact frame** (the frame where `isContact === true`, i.e., peak hip rotation) to the Gemini API as a base64 JPEG
- Gemini returns **2-3 sentences in coach-to-athlete voice** — specific, actionable, personal. Example tone: *"Your arm circle is breaking down at the top. Focus on keeping the elbow extended through the wind-up to transfer more power into your release."*
- The Gemini commentary is **saved to the DB** on first generation — persists with the video analysis so coaches see the same text on reload without re-calling the API
- Re-running is available (coach can click again to regenerate) — overwrites the saved text
- The existing `/api/analysis/vlm-eval` prototype route is **promoted** to the production integration point — update its prompt for coach-to-athlete tone, wire up DB persistence

### Pitching Angle Ideal Ranges
- Research pitching-specific biomechanics literature (PMC11969493 Fastpitch Softball Pitching Biomechanics and related sources) to establish defensible ideal ranges for pitching
- Ranges **differ from hitting** — elbow slot is wider during a windmill delivery, hip rotation timing and magnitude differs
- The `IDEAL_RANGES` constant in `flags.ts` is hitting-centric — add a `PITCHING_IDEAL_RANGES` constant (or extend the structure) for pitching-specific values

### Pitching Angle Label Rename
- When `motionType === 'pitching'`, the `MechanicsSidebar` renders different angle labels:
  - "Hip Rotation" → **"Hip Drive"**
  - "Elbow Slot" → **"Arm Slot"**
  - "Shoulder Tilt" stays as-is (same concept in pitching)
- The ideal range shown next to each label also updates to pitching-specific values

### Claude's Discretion
- Exact elbow angle threshold for Arm Circle (Bent Elbow) — pick what avoids false positives on side-view footage
- How to isolate wind-up frames for arm circle detection without a phase classifier (e.g., looking at frames before the contact frame where arm should be extended)
- Which MediaPipe landmarks identify the stride foot and power line for a right-handed pitcher
- The exact stride offset threshold that defines "significantly off power line"
- Whether Gemini route stays at `/api/analysis/vlm-eval` or moves to a cleaner path like `/api/analysis/vlm`
- DB column naming for the persisted VLM commentary (e.g., `vlm_summary` on `video_analyses`)

</decisions>
