## Decisions Made

- `extractContactFrame` uses `video.currentTime = timestampMs / 1000` then waits for `seeked` event before drawing to canvas — ensures frame is fully decoded before capture
- DB persist in vlm-eval route is wrapped in try/catch and is non-fatal — coach can regenerate even if DB write fails
- `vlmSummary` from the hook is synced to local `vlmCommentary` state via `useEffect([vlmSummary])` — clean separation between hook's DB-read responsibility and component's display state
- `motionType === 'unknown'` falls back to `'hitting'` in the fetch body — avoids Zod enum validation failure on pre-Phase-2.2 videos
