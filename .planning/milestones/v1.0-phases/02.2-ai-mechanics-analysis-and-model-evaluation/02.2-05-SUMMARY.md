## Decisions Made

- **MediaPipe keeps its role:** EVAL-01 PASS — skeleton correct on both batting and pitching clips. Key angles (elbow, hip, shoulder) approximately right. No model replacement warranted.
- **Gemini Flash as optional overlay:** EVAL-02a confirmed Gemini produces useful 2-3 sentence mechanics descriptions. Best used as a supplemental qualitative layer, not a replacement for the coordinate-based skeleton system.
- **YOLO11 deferred:** EVAL-02b skipped — yolo11n-pose.onnx not available for local testing. No evidence MediaPipe quality requires replacement at this stage. Keypoint schema difference (17 COCO vs MediaPipe 33) documented as significant migration cost.
- **Security enforced:** GEMINI_API_KEY has no NEXT_PUBLIC_ prefix; all Gemini calls in server-side API route only.
