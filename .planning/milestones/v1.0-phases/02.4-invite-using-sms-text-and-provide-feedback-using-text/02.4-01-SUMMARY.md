## Decisions Made

- **RESEND_FROM_EMAIL defaults to noreply@resend.dev** — allows dev and staging environments to send email without setting up a verified domain. Production deployments set this to their verified sender address.
- **No Resend instance singleton** — the Resend SDK client is instantiated per sendEmail() call. The SDK is lightweight (no persistent connection), and this avoids module-level initialization that could crash on cold start if the env var is not yet loaded.
- **Test uses class mock not vi.fn().mockImplementation()** — Resend is a class; `new Resend(key)` calls the constructor. Arrow function mocks fail with "is not a constructor". Using `class MockResend` with instance properties is the correct Vitest pattern for SDK constructor mocks.

## User Setup Required

**External services require manual configuration.** Developers must:
1. Get a free Resend API key at https://resend.com/api-keys
2. Add `RESEND_API_KEY=re_...` to `.env.local`
3. Optionally add `RESEND_FROM_EMAIL=noreply@yourdomain.com` (defaults to noreply@resend.dev for dev)
4. For production: verify your sending domain at Resend Dashboard -> Domains
