## Integration Findings (from integration checker)

### Critical: Middleware PUBLIC_PATHS '/' Bug
`src/middleware.ts:4` — `'/'` in `PUBLIC_PATHS` makes `startsWith('/')` always true. Edge-layer auth redirect is inoperative. Page-level guards compensate but edge protection is absent.
**Fix:** Remove `'/'` from `PUBLIC_PATHS`. Affects: AUTH-02, AUTH-04.

### Critical: Athlete Upload Assigns Wrong coach_id
`src/app/api/upload/presign/route.ts:41` — inserts `coach_id: user.id` for all users. Athlete upload video gets athlete's ID as coach_id → invisible to actual coach dashboard.
**Fix:** Pass athleteCoachId server-side to presign route. Affects: VID-01.

### High: Feedback Email Link Inaccessible to Athletes
`src/actions/feedback.ts:46` — links to `/review/${videoId}`. Review page redirects non-coach users away (`coach_id !== user.id`). Athlete cannot view their analysis.
**Fix:** Temporary: link to `/submissions` until athlete review view is built (Phase 3 v2). Affects: EMAIL-FEEDBACK-01.

### High: Resend Invite Email CTA is a Dead Link
`src/actions/auth.ts:122` — `inviteLink = .../auth/callback` (no token). Athlete click → `auth_callback_failed` error. Supabase auth email still delivers working invite.
**Fix:** Link to `/login` or remove CTA from branded email. Affects: EMAIL-INVITE-01.
